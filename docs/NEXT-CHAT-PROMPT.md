# Lời nhắn mở cuộc trò chuyện mới

Sao chép phần dưới vào chat mới; tốt nhất mở chat trong project `E:/travel-mobile-ui` hoặc đính kèm file bàn giao.

```text
Bạn tiếp tục công việc frontend mobile React Native của ứng dụng WeGo.
Thư mục làm việc chính: E:/travel-mobile-ui.

Trước khi sửa code:
1. Đọc E:/travel-mobile-ui/AGENTS.md một lần để lấy quy định chính thức.
2. Đọc E:/travel-mobile-ui/docs/AGENT-HANDOFF.md để tiếp nhận thiết kế,
   cấu trúc, quyết định của tôi, mốc kiểm tra và giới hạn hiện tại.
3. Khi cần, đối chiếu docs/PROJECT-STATUS.md và docs/HOME-PREVIEW.md,
   rồi đọc đúng component/token liên quan đến nhiệm vụ mới.
   Không cần đọc lại toàn bộ repository hoặc toàn bộ lịch sử chat.

Home đã chốt frontend ở bốn trạng thái, đang dùng mock và vào Home thẳng
trong development. Chưa nối planning, chưa dùng camera thật. Hiện không
sửa backend E:/travel-system nếu tôi chưa giao nhiệm vụ liên quan.

Giữ phong cách và các chi tiết mới nhất đã ghi trong tài liệu bàn giao.
Đừng tự thiết kế lại Home, nâng dependency, bật lại auth hay xây module
tiếp theo. Với UI nhỏ, sửa gọn và không chạy npm run lint theo yêu cầu
hiện hành; báo đúng kiểm tra thực sự đã chạy.

Khi nhiệm vụ cần UI/UX hoặc review React Native, dùng hai skill cục bộ:
- E:/travel-mobile-ui/.agents/skills/ui-ux-pro-max/SKILL.md
- E:/travel-mobile-ui/.agents/skills/vercel-react-native-skills/SKILL.md

Sau khi đọc, xác nhận ngắn bạn đã hiểu hiện trạng và chờ nhiệm vụ mới
của tôi; chưa sửa code ở bước tiếp nhận ngữ cảnh này.
```
